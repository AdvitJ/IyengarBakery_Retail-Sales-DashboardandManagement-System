IYENGAR BAKERY — RETAIL SALES DASHBOARD & MANAGEMENT SYSTEM

HOW TO RUN (Windows)
1. Extract the ZIP file.
2. Open the extracted Iyengar_Bakery_Management folder.
3. Install Python 3.10 or newer if it is not already installed.
4. Open Command Prompt in this folder.
5. Run:  py -m pip install -r requirements.txt
6. Run:  py main.py

FILES
- main.py: Complete Tkinter application.
- products.csv: Starter product catalogue.
- sales.csv: Sample sales history.
- requirements.txt: Required Python packages.
- report.txt: Project overview and features.

FEATURES
- Dashboard with revenue, sales count, active products and low-stock count.
- Revenue-by-date and top-selling-products charts.
- Add, update, search, filter, import and export products.
- Record sales with date, quantity, price and automatic stock reduction.
- View/search sales history, export records and delete a sale with stock restoration.
- CSV files are stored beside main.py, so the project can be moved to another computer.

NOTES
The included product and sales records are demonstration data for an Iyengar-style bakery.
They are editable. The program creates the CSV files automatically if they are missing.
The first launch uses the bundled CSV data; it does not overwrite existing data.
